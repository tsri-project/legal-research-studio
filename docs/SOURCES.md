# แหล่งเอกสารอ้างอิงสำหรับพัฒนา

ตรวจเมื่อ 22 ตุลาคม 2026 ลิงก์เป็นจุดเริ่มต้น ควรตรวจเอกสารปัจจุบันก่อนเปลี่ยน platform config

## เทคโนโลยี

- Antigravity Agent Skills: https://antigravity.google/docs/skills?app=antigravity-ide — ใช้ `.agents/skills/` และยังรองรับ `.agent/skills/` รุ่นเดิม
- Vite: https://vite.dev/guide/ — Node runtime และ build workflow
- Cloudflare Workers Static Assets: https://developers.cloudflare.com/workers/static-assets/
- Wrangler configuration: https://developers.cloudflare.com/workers/wrangler/configuration/
- Cloudflare Access JWT validation: https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/
- Cloudflare D1 migrations: https://developers.cloudflare.com/d1/reference/migrations/
- React: https://react.dev/

## วิธีวิจัยและแนวทางรายงาน

- PRISMA 2020: https://www.prisma-statement.org/prisma-2020
- COREQ: https://www.equator-network.org/reporting-guidelines/coreq/
- SRQR: https://www.equator-network.org/reporting-guidelines/srqr/
- OECD Regulatory Impact Assessment (2020): https://doi.org/10.1787/7a9638cb-en

Reporting guideline เป็นแนวทางรายงาน ไม่ใช่การประเมินคุณภาพครบทุกมิติหรือการรับรองรางวัล เครื่องมือ Legal → Work Mapping และ Evidence & Gap Matrix ในแอปเป็นเครื่องมือจัดระบบที่ผู้พัฒนาออกแบบ ต้องระบุที่มาให้ตรงและไม่ติดตรารับรองที่ไม่มีจริง
