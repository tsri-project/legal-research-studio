# Legal evidence review
1. Define jurisdiction, time cutoff, agency, research question and scope. Identify the controlling source before analysis.
2. Obtain the primary text from an official source. Record full title, year, amendments, effective date, section/item/page, URL and access date. Mark missing sources as unverified.
3. Map: parent Act → enabling provision → subordinate instrument → actor → power/duty → condition → work process → required evidence.
4. Preserve amendment chains and transitional provisions. Separate old obligations from new matters; never assume a transitional rule has expired without checking.
5. Write separate fields or clearly labeled passages for verbatim text, paraphrase, interpretation, observed practice and recommendation. A mismatch is an issue for review, not automatically illegality.
6. Trace each material conclusion to a precise source location. If sources conflict, retain both and formulate the question for a qualified reviewer.
7. Do not fabricate statutes or interpretive authority. Do not claim the app is a substitute for a legal opinion or that a review checklist certifies legality.
8. Update evidence records with status and limitations. Keep confidential documents out of sample fixtures and logs.
Use the evidence UI for structured records; use migrations before adding new provenance fields.
